**Fidelity review**

- Fonts and typography: System sans font, weight contrast in the month heading, small secondary labels, and compact event text follow the reference's hierarchy. Event type abbreviations appear only when columns become narrow, preventing clipping.
- The current type system uses only 12/14/16/24/30/36px roles and 400/500/600/700 weights, with 16px as the body default. Calendar metadata uses 12px; event titles and category labels separate by weight and opacity. On narrow week columns, Konwersatorium uses its short label to avoid clipping.
- Spacing and layout: The final desktop capture shows comparable sidebar and grid proportions, compact top controls, aligned date headers and hour rules, and readable event padding. The mobile layout uses a day column by default. The new month grid fills desktop space and uses a compact grid with a selected-day agenda on mobile.
- Padding, margins, and gaps follow the user's 4/8/12/16/24/32/48/64/96/128px spacing scale. Icons are 16px; compact controls are 32px high. Timed block positions continue to use class duration rather than a spacing token.
- Sidebar motion: a 240ms layout transition expands the calendar as the sidebar closes, while the sidebar content slides and fades. The motion is reversible mid-transition and reduced-motion preferences disable the movement. The top-bar toggle remains visible in either desktop state.
- Colors and tokens: The default page is neutral `#151515` and the sidebar `#111111`. The light theme uses `#faf9f7` for the page and `#f4f2ee` for the sidebar, with pale neutral controls and softer charcoal text. `#FFAE00` marks selected dates and the current-time line; blue, sage, violet, and rose distinguish class types across all three views. The full-day today tint was removed in both themes so the header and timed canvas share a consistent tone. Earlier measured light-theme contrast: body/page 10.60:1, secondary/sidebar 6.52:1, soft/sidebar 4.51:1, active view text/fill 8.87:1, and the four event-room text/fill pairs 4.81–5.07:1.
- Images and icons: The source has no required photography or illustrative assets. Navigation and detail controls use a consistent icon set, rendered sharply at the target sizes. There are no substituted logos or decorative image approximations.
- Copy and content: Polish dates, controls, class names, types, time ranges, and rooms are visible. The UI does not display sample-data labels or status markers.
